
# Olá, eu sou Kaymmi Nunes 👋

## 👨‍💻 Sobre mim

Atuo na interseção entre **desenvolvimento de software** e **educação tecnológica**. Minha trajetória reúne formação técnica, graduação em tecnologia, ensino de programação e criação de soluções web para projetos acadêmicos, educacionais, comunitários e comerciais.

- 🎓 Graduando em **Análise e Desenvolvimento de Sistemas — UNOPAR**.
- ⚡ Técnico em **Sistemas de Energia Renovável — IFPB**.
- 🐍 Foco em desenvolvimento backend com **Python, Django e Django REST Framework**.
- ⚛️ Desenvolvimento frontend com **React, TypeScript, JavaScript, HTML e CSS**.
- 🗄️ Experiência com APIs REST, autenticação, CRUD, modelagem de dados, webhooks e documentação OpenAPI/Swagger.
- 🌐 Publicação de aplicações utilizando **Cloudflare Pages e Cloudflare Workers**.
- 🤖 Interesse e experiência prática em automação, sistemas embarcados e Internet das Coisas.
