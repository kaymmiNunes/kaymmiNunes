## 👨‍💻 Sobre mim

Atuo na interseção entre **desenvolvimento de software** e **educação tecnológica**, criando aplicações e projetos voltados a necessidades acadêmicas, comerciais e comunitárias.

* 🎓 Graduando em **Análise e Desenvolvimento de Sistemas — UNOPAR**
* ⚡ Técnico em **Sistemas de Energia Renovável — IFPB**
* 🐍 Desenvolvimento backend com **Python, Django e Django REST Framework**
* ⚛️ Desenvolvimento frontend com **React, TypeScript, JavaScript, HTML e CSS**
* 🔗 Experiência com **APIs REST, autenticação, CRUD, webhooks e OpenAPI**
* 🗄️ Modelagem e integração com bancos de dados relacionais
* 🤖 Desenvolvimento de projetos com automação, sistemas embarcados e IoT
